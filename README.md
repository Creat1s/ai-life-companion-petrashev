# AI Life Companion — Полный исходный код, 3D-дизайн и документация

Персональный 3D ИИ-компаньон и голосовой суперагент управления телефоном на базе **Gemini 4 Argon (`gemini-4-argon`)** с автономным офлайн-ядром (**Local Q4 Offline Core**).

---

## 1. Что входит в этот архив проекта

- **`server.ts`** — Full-stack сервер на Express + Vite + `@google/genai` SDK (`gemini-4-argon` с автоматическим резервированием `gemini-3.8-flash`), API для умного диалога, планирования дня, генерации ответов в мессенджерах, написания постов/Reels и генерации ZIP-архива исходного кода.
- **`src/engine/threeProceduralCharacters.ts`** — Процедурные 3D WebGL-модели персонажей (Three.js):
  - **Люми (`lumi`)** — биолюминесцентный морской ангел со светящимися крыльями-плавниками и двойным шлейфом.
  - **Нова (`nova`)** — космический осьминог со спиральным глифом на лбу, светящимися антеннами и 8 щупальцами с присосками.
  - **Шэдоу (`shadow`)** — матово-чёрный неоновый кот-пантера с фиолетовыми полосами и светящимся медальоном лапки.
- **`src/components/ThreeCompanionScene.tsx`** — Интерактивная 3D-сцена с динамическим освещением (`Studio`, `Morning`, `Night`), частицами и 4 эмоциональными состояниями (`Радостный`, `Спокойный`, `Любопытный`, `Сонный`).
- **`src/components/PhoneSuperHubModal.tsx`** — Супер-хаб управления всеми функциями телефона с согласия владельца:
  1. **Звонки и Контакты**: Голосовой вызов по имени из книги контактов и приём входящего звонка голосовым согласием («Принять» / «Отклонить»).
  2. **Мессенджеры (WhatsApp, Telegram, Instagram Direct, SMS)**: ИИ готовит черновик ответа — владелец подтверждает (голосом или кнопкой) либо надиктовывает свой вариант.
  3. **Соцсети и Контент-студия (Пост / Сторис / Reels)**: ИИ сам пишет тексты и сценарии, предлагает фото, видео и файлы из галереи, и запрашивает голосовое или кнопочное подтверждение перед публикацией.
  4. **Здоровье и Психологическая поддержка 24/7**: Мониторинг пульса, стресса, сна, водного баланса, дыхательные практики 4-7-8 и живое подбадривание владельца (в том числе без интернета).
  5. **Обучение манере общения (Персона, Сленг, 18+ без цензуры)**: Настройка стиля речи помощника, обучение любимым фразам и разрешение острой/нецензурной лексики (18+) по желанию владельца.
- **`src/components/KazakhstanServicesModal.tsx`** — Голосовой вызов такси в Казахстане (**Yandex Go**, **inDrive**) и экстренных служб (**112**, **103**, **102**, **101**).
- **`src/components/SourceDownloadModal.tsx`** — Центр выгрузки полного исходного кода (`.zip`), дизайн-токенов и документации на локальный компьютер.

## 2. Как запустить приложение локально на вашем компьютере

### Требования
- Установленный **Node.js** версии 18+ или 20+
- Ключ API Gemini (опционально для облачной модели `gemini-4-argon`; без ключа приложение автоматически работает через автономное офлайн-ядро)

### Шаги запуска
1. Распакуйте скачанный архив `ai-life-companion-full-source.zip` в любую папку.
2. Откройте терминал (командную строку) в папке проекта и установите зависимости:
   ```bash
   npm install
   ```
3. Создайте файл `.env` на основе `.env.example` и укажите ваш ключ (если требуется облачный ИИ):
   ```env
   GEMINI_API_KEY=ваш_ключ_gemini_api
   ```
4. Запустите локальный сервер разработки:
   ```bash
   npm run dev
   ```
5. Откройте в браузере адрес:
   ```
   http://localhost:3000
   ```

### Сборка для продакшена
```bash
npm run build
npm start
```
